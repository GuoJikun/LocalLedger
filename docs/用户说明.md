# 净账 — 用户说明

## 第一次使用

1. 启动应用，默认进入「总览」，可看到设备信息、数据目录和各模块入口。
2. 在「设置」中确认主题（浅色 / 深色 / 跟随系统）。
3. 从支付宝或微信导出账单 CSV，进入「导入账单」。

## 导入账单

- 点击「选择文件」或直接把 CSV 拖进导入区域。
- 应用会自动识别支付宝（GBK 编码）或微信（UTF-8 BOM）账单，并显示识别结果。
- 点击「开始导入」，结果面板显示：成功、重复、跳过、自动分类与总行数。
- 未导入的行会列出行号和原因（例如交易状态非成功、金额格式异常），不会静默丢弃。
- 同一份账单重复导入不会产生重复数据：以「来源 + 交易号/交易单号」为唯一键。

## 整理流水

- 「交易流水」支持关键词、类型、分类、日期区间筛选与分页。
- 点击「编辑」可修改金额、类型、对方、备注、分类与时间；删除为软删除，不会影响统计数据。
- 没有账单里的交易可以点「手工记一笔」补录。
- 「分类管理」可维护分类层级，以及自动分类规则（关键词、匹配字段、优先级）。规则在导入时自动套用。

## 查看统计

- 「统计」展示近 6/12/24 个月的收支柱状图、指定月份的分类占比饼图与每日趋势折线图。
- 金额展示单位为元，内部一律按整数「分」计算，避免浮点误差。
- 统计口径与流水一致：只统计未删除的交易。

## 数据安全与备份

- 所有数据都保存在本机 SQLite 文件里，应用默认离线，不上传、不埋点、无账号。
- 在「设置」中可：
  - **备份数据库**：生成一致性快照；
  - **从备份恢复**：覆盖当前数据（操作前请确认）；
  - **导出流水 CSV**：UTF-8 BOM 编码，可直接用 Excel 打开。
- 建议定期备份数据库文件到自己的移动硬盘或私有云。

## 常见问题

- **识别不出账单格式**：确认文件是支付宝/微信导出的原始账单文件。支付宝部分导出为 Tab 分隔（扩展名仍是 `.csv`），本应用可自动识别逗号与 Tab 两种分隔符；若被 Excel 另存过，编码与表头可能被改写。
- **中文乱码**：本应用自动识别 GBK / UTF-8 / UTF-16；若仍乱码，请重新从平台导出原始文件。
- **金额不对**：账单金额含货币符号或千分位时会自动清洗；导入后可在流水中逐笔核对与修正。
